# Nico OS Alerte V2

Application Android reliée directement au **Nico OS local / SQLite**.

- plus de Supabase ;
- lecture de la prochaine tâche ;
- bouton **FAIT** ;
- ajout de la tâche suivante ;
- connexion par adresse locale/Tailscale + clé de liaison ;
- APK compilé automatiquement par GitHub Actions.

Le PC doit faire tourner le pont local Nico Alert V2 sur le port 8766.
